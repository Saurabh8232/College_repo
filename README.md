## 📌 Module Highlights

### 1. Data Structures & Algorithms (`/DSA_Lab_Programs_5th_Sem`)
- **Algorithms:** Bubble Sort, Selection Sort, Linear Search, Binary Search.
- **Core Concepts:** OOP (Constructors, Inheritance, Method Overriding) and Recursion (Factorials, Array operations, Subsets & Permutations).

### 2. Database Management Systems (`/DBMS_SQL_Lab_5th_Sem`)
- **Queries:** DDL/DML operations, constraints, conditional filtering, and aggregations.
- **Advanced Features:** Inner/Outer Joins, Nested Subqueries, `UNION` / `INTERSECT`, Views, and Index optimization.

### 3. HTML & CSS Development (`/HTML-CSS-Practicals_5th_Sem`)
- **Web Semantics & Content:** Semantic elements, structured lists, forms with validation, and accessible data tables.
- **Styling & Modern Layouts:** CSS variables, Box Model, Flexbox, CSS Grid layouts, and responsive media queries.

- **Algorithms & Techniques:** K-Means Clustering, Logistic Regression, K-Fold Cross-Validation, One-Hot Encoding.
- **Projects:** Real-estate House Price Prediction and Study Hours vs. Marks Prediction.
